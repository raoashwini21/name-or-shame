Opens the moment you investigate. Six lookups run in parallel.

One name. Six sources. One answer.

Every finding comes from a live lookup. Nothing is estimated from the name alone except memorability, and that's labelled as a model read.

  1. 01

    Domains

    .com, .io, .net, .ai, .app and .co, checked against the registry. When the registry doesn't answer, a DNS lookup fills in and is marked as such.

    RDAP · DNS
  2. 02

    Social handles

    Whether the plain @handle is free on X and Instagram.

    HTTP status
  3. 03

    Existing brands

    Who already uses the name in your space, searched against your one-line description.

    Web search
  4. 04

    Trademark mentions

    A signal from the open web — not a register search. Run a proper one before you file.

    Web search
  5. 05

    Similar names

    A few close variants with their own domain and search checks, in case the original is crowded.

    RDAP · Web
  6. 06

    Memorability

    How sticky, sayable and distinctive the name is, and whether it sounds like a brand that already exists.
